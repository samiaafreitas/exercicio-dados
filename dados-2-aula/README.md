# Dados - Aula 2

Visualização com matplotlib usando o mesmo dataset da aula 1 (Titanic).

Notebook: [graficos_titanic.ipynb](graficos_titanic.ipynb)

Perguntas respondidas com gráficos:

1. **Comparação:** quais grupos de passageiros (sexo + classe) mais e menos sobreviveram? (barras horizontais ordenadas)
2. **Relação:** o tamanho da família tem relação com a chance de sobreviver? (linha)
3. **Distribuição:** como as tarifas se distribuem em cada classe e onde estão os outliers? (boxplot)

Cada gráfico tem título, eixos nomeados e um parágrafo explicando o que ele mostra.

Dados: https://github.com/datasciencedojo/datasets/blob/master/titanic.csv
